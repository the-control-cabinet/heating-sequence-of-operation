# 01 System description

[← Back to README](../README.md)

- **Heat source:** a system boiler (integral pump) feeding five 2-port zone valves: two radiator circuits, one UFH circuit (mixing valve and pump), two unvented cylinders.
- **Zone control:** two Evohome controllers (upper floors: radiators; ground floor: UFH), HR92 radiator heads, HCC80R UFH controller.
- **Points list:** see the [plant monitoring I/O schedule](https://github.com/the-control-cabinet/heating-plant-monitoring-esphome/blob/main/data/io-schedule.csv).
